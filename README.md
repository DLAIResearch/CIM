# CIM
CIM: Interpretable model with consistency representation and prompt learning

Supervised learning that relies solely on class labels often provides insufficient guidance for training deep neural networks (DNNs), leading to inherent model biases and limited interpretability. To address these issues, a Consistent Interpretable Model (CIM) is proposed in this work for interpretable image classification. The proposed method is built upon three key components. First, causal analysis is employed to model the learning process of DNNs, serving as a theoretical basis for identifying spurious correlations between features and task decisions. Second, feature learning consistency is enhanced by aligning the feature representations of original images with those of task-prior objects.  Finally, the rich semantic knowledge from text encoders pre-trained via contrastive learning is leveraged to improve the alignment between the model's task feature distribution and real-world scenarios. Extensive experiments show that CIM substantially improves DNN performance, particularly in fine-grained and out-of-distribution classification (achieving over 8\% improvement in Top-1 accuracy) tasks. Moreover, CIM outperforms existing methods in terms of causality (with over a 10% gain in Grad-CAM's Overall metric) and consistency (with over a 4% gain in Grad-CAM's CH metric) of model explanations. Finally, the alignment of prompt text representations with task object representations in CIM facilitates textual explanations for DNN decisions.
